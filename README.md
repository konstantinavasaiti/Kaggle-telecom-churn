This repository contains a customer churn analysis project based on my participation in the Kaggle competition **Telecom Customer Churn – Data Quality Challenge**.

The main goal of the project is to explore and analyze customer churn behavior with a strong focus on **data quality**, **feature engineering**, and **model evaluation** using real‑world tabular data.

---

## Project Overview

Customer churn is a critical business problem for telecom companies, as retaining existing customers is often more cost‑effective than acquiring new ones.  
In this project, I worked with telecom customer data to understand key churn drivers while addressing common data quality issues found in real datasets.

The project follows an end‑to‑end data analysis workflow:
- Exploratory data analysis
- Data quality assessment
- Feature engineering
- Baseline machine learning modeling

---

## Competition Context

- **Platform:** Kaggle  
- **Competition:** Telecom Customer Churn – Data Quality Challenge  
- **Problem type:** Supervised classification (tabular data)  
- **Best score achieved:** **0,84745**

The competition emphasizes not only prediction performance but also proper handling of data quality challenges.

## Methodology

### 1. Exploratory Data Analysis (EDA)
- Distribution and summary statistics
- Churn vs non‑churn comparisons
- Detection of missing values and inconsistencies

### 2. Data Quality Assessment
- Identification of invalid or noisy values
- Handling missing and inconsistent data
- Evaluation of potential data leakage risks

### 3. Feature Engineering
- Creation of behavioral and cost‑based indicators
- Transformation of categorical variables
- Preparation of model‑ready features

### 4. Modeling
- Baseline classification approach
- Model evaluation using the competition metric
- Iterative improvements based on validation results
